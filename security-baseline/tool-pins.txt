# Pinned release binaries: <tool> <version> <SHA-256 of the linux x86_64 release asset>.
#
# scripts/install-pinned.sh downloads the asset for the version asked and installs it only when it
# hashes to the digest here (or to the caller's own <tool>-sha256, which a caller overriding the
# version must set). A mismatch, a missing digest or a failed download fails the step, before the
# binary is installed. One line per tool. Each version must equal its `<tool>-version` default in
# security-baseline/action.yml (and osv-scanner's in deps-currency/action.yml, which installs it
# through the same script); selftest-pins.sh fails when they differ. chrome-for-testing (below) has
# no such input. semgrep is pinned by the hashed lock ../semgrep-requirements.txt instead.
#
# The four release binaries were checked 2026-09-28, each three ways: GitHub's recorded asset
# digest (`gh api repos/<owner>/<repo>/releases/tags/<tag> --jq '.assets[] | {name, digest}'`), the
# vendor's own checksums file, and a download hashed locally.
#   gitleaks     gitleaks_8.30.1_checksums.txt. No signature is published.
#   trufflehog   trufflehog_3.95.6_checksums.txt, its cosign signature verified against the
#                certificate issued to trufflesecurity/trufflehog's release.yml@refs/tags/v3.95.6.
#   osv-scanner  osv-scanner_SHA256SUMS, and the SLSA provenance multiple.intoto.jsonl, its
#                signature verified against the certificate issued to slsa-github-generator for
#                google/osv-scanner@refs/tags/v2.4.0, whose subject carries this digest.
#   hadolint     GitHub records no digest for an asset uploaded before June 2025; the vendor's
#                hadolint-Linux-x86_64.sha256 matches, and the asset's updated_at is its upload
#                time (2022-11-09), so it was never replaced.
#
